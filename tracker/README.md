# Battlemat Tracker

Módulo em Python para captura de vídeo (RTSP/Webcam) e tracking de tabuleiro digital com envio de telemetria UDP para o Unreal Engine.

## Como rodar com uv

```bash
# Executar o script de teste diretamente
uv run python src/test.py

# Ou pelo script configurado
uv run tracker
```
